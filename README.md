# APS Land Services — Immersive V3 concept

A static, GitHub Pages-compatible staging concept. Upload all files and folders to the root of a new test repository. Enable GitHub Pages from the main branch/root. No build step or backend required.

## Important
- Staging pages use `noindex,nofollow`. Replace this only after final content, privacy, and QA approvals.
- The 28 highlighted states are inherited from the supplied map and require confirmation.
- Official logo and provided leadership portraits are included.
- Company statements are based on APS's public copy and the supplied Perplexity copy master.
- The privacy page is a placeholder and must not go live as-is.
- The animated wave field is an abstract illustration, not geographic/project data.
- Test navigation, map, accessibility, responsive layout and performance on real devices before publishing.
